使用提示

  • 前台地址就是本服务的根路径，把它加到浏览器书签或手机桌面。
  • 改完分类或网址，记得点左下角「保存修改」才会写回服务器。
  • 数据在 data/data.json，备份直接复制这个文件即可。
  • 放在反向代理后建议启用 HTTPS，再设置 COOKIE_SECURE=1。

导入导出

导出的 JSON 包含分类、网址与站点设置，可用于备份或迁移；浏览器书签 HTML 会被拆成站点，并按文件夹名与网址自动归类。

备份与迁移

导入会覆盖当前分类与网址，密码与保险箱不受影响。

浏览器书签

Chrome / Edge / 浏览器导出书签得到的 .html 文件；会跳过重复地址。

安全与账号

首次部署后建议立刻改掉默认的前台密码（123456）与后台账号（admin / admin123）。改密码会立即生效。
